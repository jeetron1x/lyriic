# Security Policy

## Integrity & Official Distributions

Official Windows installer packages (`Lyriic-Setup-*.exe`) distributed via [GitHub Releases](https://github.com/jeetron1x/lyriic/releases) are digitally signed with an Authenticode certificate by **Jeetron1x**.

Always verify that the installer publisher displays **`Jeetron1x`** in the Windows User Account Control (UAC) dialog before running.

## Reporting a Vulnerability

If you discover a security issue or vulnerability in Lyriic, please report it responsibly:

- **Author**: Jeetron1x
- **GitHub**: [https://github.com/jeetron1x](https://github.com/jeetron1x)
- **Contact**: Open an issue or message via [GitHub](https://github.com/jeetron1x/lyriic/issues)

Please avoid posting public exploit details before the author has had reasonable time to address the issue.
